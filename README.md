# Novex

Novex 是一款面向中文文游的 Android（安卓）应用。它以连续的人工智能对话为主界面，让用户创建、导入并长期游玩自己的世界。

**本仓库是 Novex 4.0 起的全自主代码底座**：应用的全部核心实现（传输层、数据层、运行时、界面骨架与全部业务逻辑）均为本项目自有代码。第三方组件及其许可见 [THIRD_PARTY_LICENSES.md](THIRD_PARTY_LICENSES.md)。

早期原型曾基于一个 GPL 授权的开源底座构建，该底座已在上游退出工程中被完整审计、重写并退役；3.x 及更早版本的对应源码归档于 [novex-android（只读）](https://github.com/ccbili30-collab/novex-android)，以履行对历史分发版本的源码可得性义务。

## 第一版能力

- 官方供应商接入：智谱、深度求索开箱即用（填 API Key 即连），以及任意 OpenAI 兼容自定义端点；
- 连续保存原始对话，同时在本地维护世界核心规则、当前状态与完整后台资料；
- 第一人称、第三人称、导演式编排和普通对话可自由混用；
- 使用 `【】` 或 `[]` 在同一条用户消息中表达世界外纠错；
- 使用原生可点击选项，将选择填入输入框而不自动发送；
- 使用通用 `panel`（面板）工具展示文字、图片、列表与按钮；
- 支持存档、动态世界功能菜单、中文工具状态与常见错误翻译；
- 支持把对话内容分享到另一个文游会话；
- 应用内检查更新（稳定 / 预览双通道）。

## 构建

Android（安卓）工程位于 `src/android`。需要 JDK 21（Java 开发工具包第 21 版）与 Android SDK（安卓软件开发工具包）。

```bash
cd src/android
./gradlew :app:assembleStableDebug
```
