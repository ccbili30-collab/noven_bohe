# 快速上手：三分钟了解 Novex

这一章写给刚装好的用户，也给被用户点名"教我用"的你。讲的时候用人话，别背术语。

## 你可以先聊一句试试

什么都不用准备。在首页开一个新对话，随便说点什么——让它写一段故事开头、出个角色、陪你聊一个设定，都行。Novex 的对话支持 Markdown 排版、选项按钮、可交互界面，聊着聊着你会发现它不是普通的聊天框。

## 三个最值得先知道的东西

### 1. 卡片：作品与世界的容器

Novex 的核心资产是**卡**——世界卡、角色卡、文游卡都是同一种东西：一棵"模块树"，每张模块装着一段设定、规则或资料。你不需要会写卡，对它说"帮我把刚才聊的世界做成卡"，它会建好放进你的卡库，随对话挂载、随分享导出。

**文游就是卡，卡就是文游**——文游无非是一张加了规则模块的世界卡：多了开局资料、每轮规则、本局状态和存档。启动文游在会话设置里点「活动文游 → 选择并启动文游」，玩完可以存档、结束恢复身份。

### 2. 界面：它能在对话里画界面

让它做个血条、仪表盘、小游戏面板——它写 ` ```html ` 会直接渲染成可交互界面（叫"界面岛"），还能注册"前端件"每轮只换数据不重写界面。皮肤包能整套换掉对话外观。细节见 `islands.md`、`frontend-widgets.md`、`skins.md`。

### 3. 你不用学，它会教

这本说明书你完全可以不读。任何时候对它说"读说明书教我用 XX"，它会自己去读对应章节再用人话讲给你听。说明书本身在「设置 → 文档 → 说明书」，分页目录和这同一套章节。

## 东西都放在哪

- **卡库**：对话页左侧或会话设置里管理挂载的卡；「我的」里的卡库看全部资产。
- **创作库**：「设置 → 创作与内容 → 创作库」集中看对话里生成的文档、图片、地图和卡。
- **存档**：玩文游时对它说"存档"，或点卡盘里的 Save；「Saves/Load」管理。
- **设置**：模型（LLM 提供商）、生图服务、联网、技能、灵魂（回答人格）都在「设置」里配。

## 最常问的第一批问题

- "第一次用，模型怎么接" → 「设置 → LLM 提供商 → 管理提供商」配 API key 或 OAuth 登录；支持 OpenAI 兼容中转，智谱 Coding Plan 等官方通道开箱即用。
- "侧边对话是什么" → 主对话旁的支线：从对话菜单打开，进去是一页空白对话、只共享本对话的配置，各聊各的，聊完的结论一键回传主线。
- "它说没有工具/不能建卡" → 当前模型不支持工具调用，或会话权限在「只读」。见 `troubleshooting.md`。
- "怎么让它每轮更新血条" → 前端件，见 `frontend-widgets.md`。
- "怎么导入旧卡/资料" → 统一导入，见 `workspace-and-import.md`。
- "更新了什么" → 见 `whats-new.md`。
