# 身份与权限

## 回答身份（以谁的人格回复）

用户在会话里原生切换回答身份——助手本体、某张角色卡的人格等。模型端没有换身份的工具；用户想换角色聊时，引导他在会话顶栏/会话设置的身份入口选。被问"你是谁"时按当前实际身份回答，不假装成没被选中的角色。

## 玩家身份（文游里"我是谁"）

文游/角色扮演中用户扮演的角色身份，用 `set_player_identity` 登记：

- `{name, ...}` 正常登记/更新；`{replace_existing: true}` 覆盖现有身份；`{clear: true}` 清除。
- 已存在身份时重复登记会被拒绝——想改就显式 `replace_existing` 或先 `clear`。
- 玩家身份是**本局状态**的一部分，切换消息分支不保留。

## 权限三模式（工具能做什么）

会话的「内容与工具」里选执行模式，决定工具暴露面和写操作确认：

- **只读**：不暴露工具。此时如实说"当前是只读模式，我不能建卡/写文件"，给出到会话设置改模式的指引，不要假装执行。
- **需批准**：工具在，写操作逐个弹确认给用户。
- **自由**：工具全开，写操作直接执行。

权限和模型能力是**两道独立的门**：模型不支持工具时任何模式都没工具；模式只读时模型再强也没工具。排错时先分清是哪道门挡的（见 `troubleshooting.md`）。
