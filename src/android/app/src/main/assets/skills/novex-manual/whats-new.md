# Novex 更新记录

Novex 从 0.1 至今的全部版本变更，新的在上面。用户问"最近更新了什么""某个版本有什么变化""以前有没有某个功能"时，以本章为准回答，不要凭印象编。本章篇幅较长：用 skill_read 的 offset/lines 分页读，或先按版本号定位到对应小节再读。

## 4.0.6

- 修复「前端件注册失效」：AI 注册过的面板/血条等界面现在真正持久化——注册表随会话保存、按消息分支继承。此前重试回复或编辑消息后注册跟着旧回复一起消失，AI 只能把整个界面重新写一遍（每次重试界面都不一样）；现在已注册的件在分叉后继续生效，AI 每轮只需更新数据。
- 修复「重试跑错位置」：对某条回复点重试，新回复可能错挂到更早的回合上（看起来像整段对话回退）；现在按消息的真实父子关系定位重试目标，不再被隐藏的中间过程行带偏。
- 修复「分支切换跳页」：左右切换消息分支时，阅读位置不再被甩到对话末尾，视野停留在切换点。
- 修复「卡片任务误报」：建卡时某一步报错后重试成功，任务条仍提示"另有操作未完成"；现在按整件活判断是否完成，建完不再挂着警告。
- 修复设置模块携带规则时"automatic"值被误拒：此前填系统自己推荐的 automatic 反而报错，反复重试后整批操作中断。
- 说明书更新：章节顺序按上手路径重排，补充图片生成、侧边对话、全屏舞台、文游运行时等条目，内容修订。

## 4.0.5（2026-10-11）

- 修复：正式版「导出对话包」按钮点击无响应。导出入口此前已对所有版本开放，但旧的限制条件没有清理干净，导致正式版点击后没有任何反应；现在正式版也能导出诊断包用于反馈问题。
- 说明书分册上线：「设置 → 文档 → 说明书」打开按章分页的完整说明书，一章一页、章间可翻。
- 新会话空白页新增「先看看能做什么 · 说明书 →」入口；在任何对话里对 AI 说"读说明书教我用 XX"，它会自己读对应章节再讲解——人和 AI 读的是同一本说明书。
- 更新记录并入说明书：从 0.1 到本版的全部更新历史整理为本章，逐版本详列，随时可查。
- AI 侧的说明书同步分册化：AI 只读与当前问题相关的章节，回答更准，上下文占用更少。

## 4.0.4（2026-10-10）

本版没有新功能，是一次专门的质量收口版本，适合作为稳定基准长期使用。

- 弱模型（如 DeepSeek 系列）能正常读卡和读附件文档了：此前这类模型发不出完整的资源编号，读卡、读文档的工具全部空转，现在自动容错。
- 资料学习改为用户确认制：AI 不能自行发起付费通读，发起前必须经用户确认；学习进度改为不占全屏的状态条，收起后不打断当前任务。
- 修复系统提示词自相矛盾：此前一边声明"不能建卡"、一边提供建卡工具，弱模型容易被误导；现在每个能力的说明都与实际可用功能一致。
- 修复点"停止"可能导致回复崩溃的问题。
- 修复安全问题：登录换取的令牌不再写入可分享的日志。
- 已退役的文件工具改为明确拒绝执行，防止异常调用写入文件。
- 内部清理约 4600 行废弃代码与退役功能（旧界面、旧登录链、废弃数据表）；旧版本数据自动升级，打开即用。

## 4.0.3（2026-10-10）

- 附件文档分级投递：向对话附带 docx 等文档时，软件按文档结构拆开、分档送达，不再整篇混作一团。
- 文档转卡兜底：让 AI 把小说、设定集整理成卡片时，新卡自动纳入建卡管理范围，避免"转出来了但改不了"。

## 4.0.2（2026-10-09）

- 修复会话设置保存：每轮注入与文字文风保存后重启不再丢失。
- 新增全局默认上下文上限设置；DeepSeek 可配置联网搜索后端。
- 修复 AI 改卡被陈旧草稿遮蔽的问题：编辑页遗留的旧草稿不再挡住 AI 的读写，它读写的一直是卡的当前版本。

## 3.0.2（2026-09-16）

本版让"AI 主持的文字游戏"具备完整运行时：公平的骰子、不漂移的账本、一键定调的文风，以及五个开箱即用的写作与建卡技能。

- 文游运行时：「每轮注入」页新增两个开关（默认关闭）。骰值注入——每次发送自动附带 2 枚客户端真随机骰值，AI 只能解读、不能篡改；账本回传——上一轮状态账本与回合数自动回传下一轮，叙事与账目不符时按账本修正，长局状态不漂移。
- 文字文风：内置 32 张题材文风卡（仙侠、玄幻、都市、悬疑、科幻末世、女频等，来自开源项目 oh-story-claudecode，MIT 协议、署名随附），点选即整局生效，也支持手写自定。
- 内置技能五件套：文游制作机（五步产出一可开局的世界卡）、卡整理机（文档转卡、原文保真不润色）、humanizer-zh 与 human-writing（去 AI 味双技能）、skill-creator。
- 前尘 API 中转预设：地址协议预填，装好即用；接口失败自动换通道重试；供应商页新增接口方向选择（OpenAI Responses / Anthropic Messages）。
- 本局状态升级：AI 可修改和删除状态字段；数值可声明上限并自动渲染为进度条（低值变红）；面板可缩放折叠；新一轮状态先继承旧值再叠加变化。
- 体验修复一批：思考过程实时可见、长对话发送不再先卡十几秒、书签改为横向标签页、收起改为原地淡化、侧边回传全程有状态条且失败可重试。
- 稳定性：设置保存不再被 AI 同期写入挡住；选项渲染按会话工具状态给出按钮或文字列表；会话列表行尾操作收进菜单；导出对话包对所有通道开放。
