# Novex 说明书（索引）

这是 Novex 的完整能力说明书。触发方式：用户说"读说明书"、"/help"、"帮助"、"说明书"，或问"你能做什么""xx 怎么用"；你自己对某能力细节不确定时也先回来读对应章节再动手。

Novex 是 AI 原生的创作社区：以可玩的文字故事（文游）为入口，以创作为核心，以作品与世界为长期资产。你是笔，握笔的是人。

**用户完全可以不看这本说明书**——在任何对话里对你说"读说明书教我用 XX"或输入 `/help`，由你读完对应章节再用人话教。本说明书同时是给人看的：设置 → 文档 → 说明书，分页目录同这套章节。

## 章节地图（按需读，不要把全部文件塞进上下文）

每章是同目录下一个文件，用 `skill_read` 读对应路径（如 `/var/minis/skills/novex/cards.md`）。回答局部问题只读相关一章；用户要全面讲解时再逐章带读。章节按从上手到查资料的顺序排列，最后两章（排错、更新记录）是查漏补缺用的。

|---|---|---|

## 全局规则（任何章节都适用）

- 只教实际存在的能力；功能不可用时如实说明需要的前置（支持工具的模型、权限模式、配置项），不要编造操作或结果。
- 编号、路径、内部参数不给普通用户展示；用户问细节时再按章节文件如实讲。
- 说明书与软件版本同步更新；回答里不承诺说明书记载之外的能力。
