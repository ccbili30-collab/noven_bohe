# 聊天正文渲染清单（画布事实）

Novex 聊天正文是 Markdown 渲染器 + 界面岛两层。写正文排版或教用户前，先对一遍这份清单——写了不渲染的格式等于白写。

## 正文 Markdown 支持的块

- 段落、标题（`#`–`######`）、引用块（`>`）、有序/无序列表、任务列表（`- [ ]`）、分割线（`---`）
- 表格：标准 `| a | b |` + 分隔行写法，渲染成真表格
- 围栏代码块（``` 开头结尾），带语言名有语法着色
- 图片：`![描述](引用)`，URL 用工具回执里的 `novex://` 引用；独立的图片行单独成块
- 数学：见下节

## 数学：KaTeX 渲染，正文内使用

**KaTeX 在 Novex 首先是"极简画布"，其次才是公式排版。** 血条、量表、阵营条、冷却条这类小可视化，默认用 KaTeX 色块拼——比 ASCII 字符画好看，比 ```html 岛轻。

### 画布原语（记住这四个就够）

- `\textcolor{#RRGGBB}{\rule{宽度}{高度}}` —— 实心色块。`\rule` 画黑矩形，外套 `\textcolor` 上色。
- `\colorbox{#RRGGBB}{内容}` —— 给内容垫底色。
- `\fcolorbox{边框色}{底色}{内容}` —— 描边色块。
- `\boxed{内容}` —— 细边框包住。

### 常用配方

- **血条**：`\textcolor{#c0392b}{\rule{6em}{0.9em}}\textcolor{#3a3a3a}{\rule{4em}{0.9em}}` —— 两段 `rule` 宽度按"当前值/上限"比例算，接起来就是一条渐变槽。em 是相对单位，总量控制在 ~10em 不溢出手机宽度。
- **带数值的条**：`\colorbox{#2d6a4f}{\;\color{white}\text{HP 72/100}\;}`。
- **分段量表**（如五格怒气）：`\textcolor{#e67e22}{\rule{1.6em}{1em}}\ \textcolor{#e67e22}{\rule{1.6em}{1em}}\ \textcolor{#444}{\rule{1.6em}{1em}}`——每个格子一条 `rule`，亮几格画几格。
- **标签行**：`\text{HP }` + 条 + `\text{ 72/100}`，文字与色块在同一式内混排。

### 公式排版（真要用数学时）

- 行内：`$…$` 或 `\(…\)`。短式子（$x_i$、$f(x)=5$）留在行内。
- 独立块：`$$…$$` 或 `\[…\]`，单独占一行渲染居中大公式。
- 宽的行内式子（含 `\frac`/`\sum`/`\int`/`\sqrt`/矩阵 `\begin{…}`/长式）会自动提升为块状显示，不用特意换语法。
- KaTeX 覆盖常用符号、上下标、分式、根号、求和积分、矩阵（bmatrix/pmatrix/cases）、`\mathbf`/`\mathbb`/`\mathcal`、`\binom` 等。
- **界面岛内没有 KaTeX**。岛里的数学排版用 HTML/CSS（上下标用 `<sup>`/`<sub>`，分式用两个 div + 边框线）或直接写 Unicode 符号。

## 界面岛块

```html
<div class="panel">…</div>
<style>…</style>
<script>…</script>
```

- 块内容按 HTML 片段处理：不写 `<!DOCTYPE>`/`<html>`/`<body>`，`<style>`/`<script>` 直接放块里。
- 语言名写 `html`（`xhtml` 也认）。围栏闭合行必须是不带任何文字的 ` ``` `；块内不能出现 ` ``` ` 开头的行。
- 流式期间岛先以源码形态显示，块闭合后才变身界面——这是正常过程，不是 bug。
- 裸 HTML（不带围栏）也会被识别成岛：以块级标签（div/section/table/form/ul/ol/h1–h6/p/blockquote/pre/canvas/video/audio 等）开头的段落序列，且内含 `</…>` 闭合标记。**仍推荐写围栏**，裸写法是容错不是规范。

## NOVEN_FRAME 数据桥

```js
const F = window.NOVEN_FRAME;   // 脚本执行前已就绪
F.card    // {name, kind} —— 当前挂载卡；无挂载时可能缺省
F.state   // {变量名: 字符串|数字|布尔} —— 本局剧情变量；空对象=尚无数据
F.max     // {变量名: 上限} —— 仅声明了上限的数值变量才有
F.theme   // {dark: 布尔, accent/text/surface: '#RRGGBB'} —— 应用主题
```

- 更新通道：`window.addEventListener('noven:frame', fn)`——`update_playthrough_state` 写回状态后派发，fn 里重读 F 重绘。
- state/max 的键名就是剧情里登记的变量名（如 `血量`、`好感度`）。读不到的键按"无数据"处理，不伪造。
- 需要变量时先在剧情流程里用 `update_playthrough_state` 登记，再让岛读——顺序是先更新状态再出岛。

## 岛的运行时事实

- 宽度 = 气泡宽度（手机约 320–380px），`width:100%` 即可；高度随内容量出，超过约 520px 时岛内部滚动。
- 背景透明：不写背景色就透出气泡底色，务必自行声明底色。
- CSP：仅内联脚本/内联样式/`data:`、`blob:` 图片字体；其他一切资源被掐。
- 右上角有半透明 `</>` 悬浮钮，用户可切看源码——别试图隐藏它，写经得起看的代码。
- 无法弹窗、无表单、无存储、无网络。交互=点击/滚动/动画/读 NOVEN_FRAME。

## 何时不用岛

- 结构化资料（属性表、图鉴、清单）：优先 `render_panel` 面板工具（若本轮提供）或 Markdown 表格——面板有折叠、图标、动作按钮等系统表现。
- 纯数据查询结果：Markdown 表格足够，不必为了"看起来像界面"而上岛。
- 剧情正文：普通文字，别包界面。
